### Практика

**Вариант № 2**

В процессе функционирования АСУ ВД в файле фиксируются данные о самолетах, выполняющих полет в зоне действия АСУ. Каждая запись имеет структуру типа:

| Б-3726         | РЕЙС1763    | ТУ-154М  | 17:35              |
|----------------|-------------|----------|--------------------|
| бортовой номер | номер рейса | марка ЛА | время входа в зону |

1) подготовить программу, сортирующую записи с использованием индексной сортировки методом «пузырька» в порядке возрастания номеров рейсов; результаты печатать в виде таблицы;

2) обеспечить входной контроль бортового номера, цифровой части номера рейса и времени входа в зону, выполнить отладку и тестирование.

+ Чтение данных их файла производить с использованием функций ввода/вывода языка С++.

+ Алгоритм должен быть параметризован; обмен данными с подпрограммой должен осуществляться только через параметры; исходные данные хранятся в отдельном файле.
